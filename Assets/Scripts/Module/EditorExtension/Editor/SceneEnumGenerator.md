# 📝 プログラム生成 仕様書

## 1. プロジェクト概要

- **タイトル**： SceneEnumGenerator
- **目的 / 背景**： SceneをEnumによって表現したいが、手作業で生成することが面倒なため。

---

## 2. 対象環境

- **開発言語**： C#
- **フレームワーク / ライブラリ**： Unityエディタ拡張

---

## 3. 入出力仕様

- **入力形式**： エディタウィンドウからシーン取得ディレクトリ・生成ファイル・Enum型名を入力
- **出力形式**： 生成ファイルにEnumを生成
- **エラーハンドリング**： Debug.LogError

---

## 4. 想定するコード構成

- **ファイル構成**：
  ```text
  /Assets/Scripts/Module/EditorExtension/Editor/
  ```
- **アーキテクチャ**： 複数ファイルに分かれる場合はディレクトリを作成すること。
- **命名規則 / インターフェースの指定**： 周囲の命名規則に合わせる。
